Project Justification

En la actualidad el sistema educativo se enfrenta a una crisis dado el enfoque memorístico que ha tenido durante los últimos siglos, dicho enfoque deja escasos momentos para enfrentarse a problemas nuevos, desarrollar la intuición y ganar confianza frente a un mundo que cambia rápidamente. La población necesita herramientas para enfrentarse al mundo moderno donde la creatividad y la resolución de problema son habilidades cada vez más valiosas. Defstuf es una aplicación que permite asimilar grandes cantidades de información como definiciones y teoremas de forma eficiente, dándole así tiempo al usuario para que realice más actividades que le permitan crecer y que le llenen.

Defstuf

Funcionalidades:

  • Asimilación eficiente de definiciones y teoremas
  • Sistema de repetición espaciada para optimizar el aprendizaje
  • Interfaz intuitiva para gestionar contenido educativo
  • Plataforma para desarrollar habilidades de resolución de problemas

Technologies and Architecture

Tech Stack: Java Spring Boot, Thymeleaf, MySQL, Bootstrap 5

These technologies were chosen for their flexibility and maintainability. Spring Boot provides a robust and scalable ecosystem, while Thymeleaf allows efficient creation of dynamic views. MySQL ensures reliable data persistence, and Bootstrap guarantees a responsive and modern interface.
