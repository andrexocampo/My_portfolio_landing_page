Project Justification

In our rapidly changing, data-overloaded world, there is an urgent need to expand our learning toolkit. All critical thinking and problem-solving capability are built upon a solid memory foundation. This is the purpose of Defstuf: to streamline the process of collecting and memorizing definitions and theorems, employing specific tools--such as the integrated clipping tool--and proven methods, like spaced repetition.

The solution: Defstuf

Features:

  • Create your profile and manage: study areas, review notes for each concept, and the bibliographic sources from which you extract each one.
  • Generate review notes instantly: capture and organize key concepts with the integrated clipping tool.
  • Automate your review schedule: the system creates spaced repetition sessions based on scientific principles to ensure long-term knowledge retention.

Technologies and Architecture

Tech Stack: JavaFX 13, MySQL 8.2 + JDBC, Git, Maven, BCrypt, MVC, DAO

The application features a layered architecture, with MVC and DAO patterns, achieving a modular and flexible design that allows for the future addition of various types of concepts, such as identities, in addition to definitions and theorems. Its database is designed to be scalable, storing metrics such as study time and user response history, which opens up the possibility of implementing advanced data analysis functionalities to enhance the learning experience and the user's perspective.

Project Justification

Manual vehicle maintenance management generates stress and potentially costly failures due to oversights. Maintenance Manager solves this by centralizing all maintenance tasks, alerting you about upcoming due dates, and generating clear cost statistics. It transforms the chaos of maintaining one or multiple vehicles into control and financial foresight.

The solution: Maintenance Manager

Features:

  • Centralizes your vehicle fleet information. Create an independent profile for each vehicle and access its history in an organized manner.
  • Schedule and budget for upcoming maintenance. After completing each service, mark the record as finished, maintaining an accurate and up-to-date financial history.
  • Stay on track with proactive alerts. The application will notify you in advance when maintenance is due, helping you plan and avoid costly oversights.

Technologies and Architecture

Tech Stack: Spring Framework 3.5.6, Java 21 LTS, Git, Maven, Spring Data JPA / Hibernate, Spring Security, Thymeleaf, Bootstrap 5, Chart.js, MVC, DAO

A web application developed with the Spring Framework and a scalable MVC architecture. It implements Spring Security, JPA/Hibernate with MySQL, and email notifications for production. Features a modular design that facilitates the integration of data analysis.

Project Justification

Many struggle to structure their workday, either by working non-stop or resting without a plan. Phaselock Timer solves this by integrating time-block planning with work/rest rhythm (Pomodoro). The app allows customization of work and break cycle durations, distributing these cycles within a given time block to ensure maximum utilization of the period allocated to a specific task.

The solution: Phaselock Timer

Features:

  • Define time for your task, start the timer, and forget about interval management. Phaselock Timer will automatically notify you when to switch between work and break.
  • Configure work and break times to your needs. The app will sequentially distribute them throughout the scheduled session.
  • Review the automatic planning. The application provides a clear view of how cycles have been allocated within the time you defined.

Technologies and Architecture

Tech Stack: Spring Boot 4.0.0, Java 21 LTS, Git, WebSocket, JavaScript, RESTful API, Dependency Injection

PhaseLock Timer is a full-stack productivity application built with Spring Boot 4.0 and Java 21, implementing industry-standard architectural patterns. The backend features a RESTful API design with proper separation of concerns through DTO pattern, Service Layer, and Repository pattern for data abstraction. Real-time capabilities are achieved via WebSocket (STOMP protocol) for bidirectional communication, eliminating polling overhead. The application employs dependency injection, bean validation, and comprehensive exception handling with a centralized GlobalExceptionHandler. Frontend uses vanilla JavaScript with Web Audio API and Browser Notifications for native integrations.
